# graphics-sundbox

three.js のシェーダー / グラフィックス実験場。リポジトリ直下で `npx serve` して各サブディレクトリを開く。

- ice-fake-translucency: 半透明のように見える不透明の氷
- eye-effect: 瞳のレンズとうるうる表現 (miku.glb)
- volumetric-fire: Real-Time Procedural Volumetric Fire (I3D 2007)
- parallax-occlusion-mapping: POM / SPOM
- hydraulic-thermal-erosion: 格子ベースの水力侵食 + 熱侵食 (Jákó 2011)
- improved-terrain-generation: パーティクルベースの水力侵食
- dual-paraboloid-map: DP マップのベイカーと cubemap との比較
